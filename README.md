# Good Deeds

> Make kindness visible. Make goodness contagious.

A social feed of real good deeds, recognized by the people who witness them. Launching in Bangalore.

- Product requirements: [docs/PRD.md](docs/PRD.md)
- Build roadmap: [docs/ROADMAP.md](docs/ROADMAP.md)

## Run locally

Requires Docker Desktop.

```
docker compose up -d --build
```

- Web app: http://localhost:5173
- API: http://localhost:8000 (docs at http://localhost:8000/docs)

See [CLAUDE.md](CLAUDE.md) for development commands and architecture.
